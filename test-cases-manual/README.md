# Casos de Teste Manuais

Esta pasta contém a documentação dos casos de teste manuais executados nas funcionalidades de **Login e PIM (Personnel Information Management)** do OrangeHRM.

## Arquivos

- **Login-test-cases.xlsx** — casos de teste da funcionalidade de Login.
- **PIM-test-cases.xlsx** — casos de teste da funcionalidade PIM.
- **README.md** — documentação desta pasta.

Os casos de teste foram elaborados, executados e documentados com base no comportamento observado durante os testes da aplicação.
